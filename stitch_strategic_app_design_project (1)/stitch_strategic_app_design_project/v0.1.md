# 모임예약플랫폼 — 화면 목록 체크리스트 (v0.1)

기획서 v0.5 기준, 8개 역할별 필요 페이지를 정리한 개발 스코프 체크리스트입니다.
각 항목은 관련 PRD 장절을 참고로 표기했습니다. `[MVP]` `[Phase2]` 표시로 구현 우선순위를 구분합니다.
